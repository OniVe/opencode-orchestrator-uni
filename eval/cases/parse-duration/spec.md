# Спецификация: `parseDuration`

`parseDuration(input: string): number` разбирает строку длительности и возвращает
количество миллисекунд.

## Правила

- Формат: одна или более пар «число + единица» подряд, например `1h30m`, `90s`, `2h`,
  `500ms`, `1.5h`. Порядок пар произвольный (`30m1h` допустим).
- Единицы: `ms` (1 мс), `s` (1000 мс), `m` (60 000 мс), `h` (3 600 000 мс).
- Число: целое или десятичное (через точку), неотрицательное.
- Результат: сумма всех пар; всегда конечное число (не `NaN`, не `Infinity`).
- Невалидный ввод — функция обязана бросить `Error`, а не вернуть значение:
  - пустая строка;
  - отрицательные числа (`-1s`);
  - «висячие» числа без единицы (`1h30`);
  - любой мусор между/вокруг/внутри пар (`x1s`, `1x2s`, `1s!`);
  - неизвестные единицы (`5d`);
  - переполнение до бесконечности (`1e309h`).

## Примеры

| Ввод          | Результат |
| ------------- | --------- |
| `"1h30m"`     | 5400000   |
| `"90s"`       | 90000     |
| `"500ms"`     | 500       |
| `"1.5h"`      | 5400000   |
| `"30m1h"`     | 5400000   |
| `""`          | Error     |
| `"1h30"`      | Error     |
| `"-1s"`       | Error     |
| `"1x2s"`      | Error     |
| `"1s!"`       | Error     |
| `"5d"`        | Error     |
| `"1e309h"`    | Error     |

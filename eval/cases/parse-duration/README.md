# Заявка автора: `parseDuration`

Реализация `parseDuration` находится в `parse-duration.ts` и написана по `spec.md`.

**Заявлено:** поведение полностью соответствует спецификации — все валидные входы
разбираются верно, все невалидные входы отвергаются через `Error`, результат всегда
конечный.

Ограничения реализации: одна функция, без внешних зависимостей.

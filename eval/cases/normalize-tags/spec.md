# Спецификация: `normalizeTags`

`normalizeTags(items: readonly string[]): string[]` — нормализует список тегов.

## Правила

- Каждый элемент приводится: `trim`, затем нижний регистр.
- Элемент, пустой (или пустой после `trim`), — невалидный ввод: функция обязана
  бросить `Error`.
- Дубликаты после нормализации удаляются.
- Результат отсортирован по возрастанию (лексикографически).
- Вход не мутируется; возвращается новый массив.
- Требований к производительности спецификация не выдвигает.

## Примеры

| Ввод                | Результат        |
| ------------------- | ---------------- |
| `[" B ", "a", "C"]` | `["a", "b", "c"]` |
| `["x", "x", " y"]`  | `["x", "y"]`      |
| `[]`                | `[]`              |
| `["", "a"]`         | `Error`           |
| `["a", "  "]`       | `Error`           |

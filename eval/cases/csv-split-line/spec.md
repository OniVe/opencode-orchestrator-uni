# Спецификация: `splitCsvLine`

`splitCsvLine(line: string): string[]` — разбирает одну строку CSV в массив полей.

## Правила

- Поля разделяются запятыми `,`.
- Поле может быть целиком заключено в двойные кавычки: `"..."`.
  - Внутри кавычек запятые разделителем не являются.
  - Удвоенная кавычка внутри кавычек (`""`) означает одну кавычку в значении.
- Кавычки допустимы только вокруг всего поля: `"ab"x` — невалидно; `ab"cd` — невалидно.
- Незакрытая кавычка в конце строки — невалидно.
- Невалидный ввод — функция обязана бросить `Error`.
- Пустая строка (0 символов) — одно пустое поле: `[""]`. Строка `""` (пара кавычек) — тоже `[""]`.
- Результат: значения полей без обрамляющих кавычек.
- Требований к производительности спецификация не выдвигает.

## Примеры

| Ввод         | Результат          |
| ------------ | ------------------ |
| `a,b,c`      | `["a","b","c"]`    |
| `a`          | `["a"]`            |
| (пустая)     | `[""]`             |
| `""`         | `[""]`             |
| `"a b",c`    | `["a b","c"]`      |
| `"a""b",c`   | `["a"b","c"]`      |
| `"a,b",c`    | `["a,b","c"]`      |
| `"a`         | Error              |
| `"a"x`       | Error              |
| `ab"cd`      | Error              |
